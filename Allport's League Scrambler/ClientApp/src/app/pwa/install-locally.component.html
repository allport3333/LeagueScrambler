On iPhone or iPad

For these steps, open this website in Safari.

  1. Open Safari’s Share menu share.
  2. Select Add to Home Screen. You may need to scroll the share menu.
  3. Turn on Open as Web App when that option is available.
  4. Tap Add.

On Android

  1. Open this website in Chrome or another browser that supports installation.
  2. Open the browser menu and choose Install app or Add to Home screen, if offered.
  3. Confirm the installation.

On your computer

In Edge, open the browser menu, then Apps → Install this site as an app, if offered.

In Chrome, use the install icon in the address bar, or open the browser menu and look for Install Allport's League Hub under Cast, save, and share, if offered.

If your browser offers Add to Dock or an install option, you can use it. Otherwise, open this page in Chrome or Edge for supported installation options.

Installation options vary by browser. If the app is already installed, open it from your home screen or application launcher.

Same account. Same league data. Installation is optional, and the website continues to work as usual. You may need to sign in again in the installed app.

An internet connection is needed for current information and saving scores or attendance.

Printing from the app

Use the existing Print actions on schedules and matchups. If the app window cannot open printing, open the website in Safari, Chrome, or Edge and print there instead.
