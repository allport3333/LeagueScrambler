## Evidence limits

The connected GitHub tool rejects Dependabot endpoints, and the local Git credential helper has no usable GitHub credential. Therefore the six **private alert records, manifest paths and exact alert-to-GHSA mappings could not be retrieved**. The IDs/severities below are those supplied by the user. Public reviewed GitHub advisories, registry metadata, installed dependency chains and the npm bulk advisory endpoint were inspected directly. Multiple advisories match node-forge/router/brace-expansion; the report does not invent an exact private alert mapping. Remote alerts remain open until reviewed changes are pushed/merged and GitHub rescans; no remote status change is claimed.

## Public advisory details

- proxy-addr: [GHSA-jqcg-44mw-7w3h](https://github.com/advisories/GHSA-jqcg-44mw-7w3h), CVE-2026-90711, `>=1.1.0 <2.0.8`, fixed2.0.8. A trust subnet such as `::ffff:10.0.0.0/8` incorrectly trusts arbitrary IPv4 clients; ordinary IPv4 notation or correct mapped `/104` avoids that configuration issue. Fixed package rejects the cross-family bypass.

## Production/SSR inspection

The project has `BuildServerSideRenderer=false`. The only Node renderer build and node_modules publish entries are conditional on that flag being true. There is no main.server/AppServerModule, server target, renderModule, prerender middleware or Razor prerender tag in current source. Startup serves `ClientApp/dist` in production and calls UseAngularCliServer only inside IsDevelopment(). BrowserModule.withServerTransition alone does not render on a server.

Removed unused direct `@angular/platform-server`, `@nguniversal/module-map-ngfactory-loader` and `aspnet-prerendering`, pruning11 installed packages. The existing unused SSR conditional is not enabled. No actual production machine/configuration was accessed; these conclusions concern checked-in hosting/build code, not an unverifiable deployed override.

The two older root/ASP.NET-directory lockfiles have no corresponding package.json and are not used by the current frontend/test install or .NET publish working directory. They contain none of the six target packages and were left untouched.
